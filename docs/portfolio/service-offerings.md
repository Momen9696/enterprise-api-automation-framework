# Suggested Upwork services

## API automation framework setup

Design a Robot Framework and Python framework for an existing REST API: environment profiles, token handling, schema checks, data-driven suites, and a GitHub Actions workflow that publishes reports.

## Regression suite for account or order APIs

Add positive and negative coverage for authentication, authorization, validation, pagination, and idempotent writes. Use synthetic or sandbox data only.

## CI quality gate

Wire Pytest and Robot runs to pull requests, fail the build on test or dependency-audit failures, and store JUnit, HTML, and Allure artifacts.

## Framework rescue

Split a single large Robot file into keywords, a Python client, and data files. Add masking and stop unsafe retries on POST.

Typical first milestone: one service, one environment, a passing suite in CI, and a short execution guide the client's team can run locally.
